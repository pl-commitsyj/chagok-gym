# 차곡 · 나의 운동 기록

React + TypeScript + Vite로 만든 개인 운동 기록 PWA입니다. APK가 아니며 로그인, 데이터 서버, 광고, 분석 도구가 없습니다. 정적 파일 호스팅만 필요합니다. 운동 기록은 방문한 주소의 브라우저 IndexedDB에만 저장합니다.

## PC에서 처음 실행하기

1. Node.js LTS를 설치합니다: https://nodejs.org/ko
2. 이 폴더를 열고 주소 표시줄에 `cmd`를 입력한 뒤 Enter를 누릅니다.
3. `npm install`을 입력합니다. 처음 한 번 인터넷 연결이 필요합니다.
4. `npm run build`를 입력합니다. 배포용 `dist` 폴더가 생성됩니다.
5. PC 미리보기는 `npm run preview` 실행 후 표시된 localhost 주소를 엽니다. 종료는 Ctrl+C입니다.

`index.html`을 파일로 직접 열면 실행되지 않습니다. 휴대폰에서 PC의 HTTP LAN 주소를 여는 것은 PWA 설치·오프라인 확인 방법이 아닙니다. 휴대폰에는 아래 HTTPS 배포 주소를 사용하세요.

## 가장 쉬운 배포: Cloudflare Pages

배포 계정은 앱 이용자 로그인과 별개입니다. 앱 자체에는 로그인 기능이 없습니다.

1. Cloudflare 대시보드에서 Workers & Pages → Pages → 직접 업로드(Upload assets)로 새 프로젝트를 만듭니다. 화면 이름은 계정과 언어에 따라 다를 수 있습니다.
2. `npm run build`로 생성한 **dist 폴더의 내용**을 업로드하고 배포합니다. 소스 폴더 전체나 node_modules는 올리지 않습니다.
3. 발급되는 `https://프로젝트이름.pages.dev` 주소를 휴대폰에서 엽니다.
4. 수정할 때는 다시 빌드한 dist로 동일 프로젝트에 새 배포를 만듭니다.

Git 연동 방식은 빌드 명령 `npm run build`, 출력 폴더 `dist`, Node.js 22를 사용하세요. 로컬 DB나 API 설정은 없습니다.

## GitHub Pages 배포

1. GitHub에서 새 저장소를 만들고 이 프로젝트 소스를 업로드합니다. `node_modules`, `dist`는 업로드하지 않습니다.
2. Settings → Pages → Source에서 GitHub Actions를 선택합니다.
3. 함께 제공한 `.github/workflows/deploy.yml`은 main 브랜치에 올리면 자동 빌드·배포합니다. 기본 브랜치가 다르면 workflow의 main을 바꾸세요.
4. Actions가 성공하면 Settings → Pages에 표시되는 HTTPS 주소를 휴대폰에서 엽니다.

Vite의 상대 경로 설정 덕분에 `https://사용자.github.io/저장소/`에서도 작동합니다. 배포 주소를 바꾸면 저장 공간도 달라집니다. 주소 변경 전 JSON을 백업하고 새 주소에서 복원하세요.

## 갤럭시에 설치하기

1. 인터넷이 연결된 상태로 배포된 HTTPS 주소를 Chrome에서 엽니다.
2. 설정 화면에서 **오프라인 준비 완료**를 확인합니다. 첫 방문 직후에는 캐시 저장에 시간이 걸릴 수 있습니다.
3. Chrome 메뉴 ⋮ → 홈 화면에 추가 → 설치를 선택합니다. 설치 안내가 보이면 앱 설정의 설치 버튼도 사용할 수 있습니다.
4. 삼성 인터넷은 메뉴 ☰ → 현재 페이지 추가 → 홈 화면을 이용합니다. 브라우저 버전에 따라 문구가 다를 수 있습니다.
5. 홈 화면의 차곡 아이콘으로 실행합니다. 비행기 모드로 바꾸고 앱을 다시 열어 오프라인 실행을 확인하세요.

앱 설치 여부·설치 메뉴는 실제 기기의 브라우저에서 최종 확인해야 합니다. iOS/Android 스토어 파일이나 APK는 제공하지 않습니다.

## 운동하기

- 오늘의 운동에서 의료 안내를 읽고 운동 시작하기를 누릅니다.
- 첫 1~2주는 가벼운 중량과 1~2세트로 시작하도록 근력 운동 초기값을 2세트로 설정했습니다. 일반 루틴 권장값은 각 3세트입니다. 설정에서 운동별로 1~10세트와 반복 횟수를 바꿀 수 있습니다.
- 러닝머신 워밍업은 5~10분, 마무리는 5분입니다. 시간 입력은 분 단위입니다.
- 기구 및 사용 방법 보기를 펼치면 교체용 기구 그림, 사용 방법, 주의사항을 봅니다.
- 중량과 반복 횟수를 입력하고 완료를 체크하세요. 이전 종료 운동의 중량이 자동 입력됩니다. 근력 세트 완료 시 휴식 타이머가 시작됩니다.
- 휴식은 60/90/120초 중 선택하며 다시·건너뛰기를 사용할 수 있습니다. 종료 시각으로 계산하므로 화면을 벗어나도 정확합니다. 백그라운드 소리 알림은 제공하지 않습니다.
- 일시정지하면 운동 시간도 멈추고 휴식 타이머는 취소됩니다. 다시 시작으로 이어갑니다.
- 입력은 자동 저장됩니다. 앱을 닫아도 진행 중 운동을 불러옵니다. 단, 브라우저 저장 실패 안내가 있으면 JSON 백업부터 해주세요.
- 운동 종료 후 운동 기록에서 날짜, 시간, 세트 입력을 수정하거나 삭제할 수 있습니다. 미완료 세트도 구분해 보관합니다. 비교 수치는 완료한 근력 세트의 중량×반복 합계이며 건강 평가가 아닙니다.

## 백업과 복원

설정 → JSON 내보내기를 눌러 파일을 보관하세요. 새 기기나 주소에서 JSON 복원으로 가져옵니다. 최대 10MB이며 버전, 운동 ID, 세트 수, 입력 범위, 기록 형태를 검사합니다. 확인 화면에서 덮어쓰고 복원을 눌러야 실제 데이터가 바뀝니다. 기존 기록은 합쳐지지 않습니다. 진행 중인 운동은 복원 시 일시정지됩니다.

브라우저 데이터 삭제, 시크릿 모드 종료, 기기 초기화, 저장 공간 정리는 기록을 지울 수 있습니다. Chrome과 삼성 인터넷의 데이터는 서로 공유되지 않습니다. 정기적으로 백업하세요.

## 이미지 교체와 권한

`public/equipment.svg`는 이 프로젝트를 위해 직접 만든 공통 임시 그림이며 실제 기구 사진이 아닙니다. 사용자 요청에 따라 사진 교체가 가능한 영역을 제공했습니다. `src/model.ts`의 각 운동 항목에 사진 경로를 추가하고 `src/main.tsx`의 기구 img src를 연결하면 개별 사진으로 바꿀 수 있습니다. 직접 촬영했거나 오프라인 재배포 허용 라이선스를 확인한 사진만 `public`에 넣으세요. 출처·저작자·라이선스는 함께 기록하세요. 외부 URL 이미지 대신 로컬 파일을 사용하고 Workbox 캐시 확장자에 jpg/webp를 추가하면 교체 사진도 오프라인에 저장됩니다. 아이콘과 안내 그림은 직접 제작한 SVG입니다.

## PWA와 업데이트

- Vite PWA 플러그인이 빌드 시 `dist/manifest.webmanifest` 및 Service Worker를 생성합니다.
- 192·512px PNG 아이콘과 512px maskable 아이콘을 포함합니다.
- HTML, JS, CSS, SVG, PNG를 사전 캐싱하며 이전 버전 캐시를 정리합니다.
- 새 버전이 대기하면 상단 업데이트 버튼이 나타납니다. 운동 종료 후 누르세요. 기록 DB는 캐시와 별개로 유지됩니다.
- 시스템 한국어 글꼴을 사용하여 외부 폰트 다운로드가 없습니다.

## 건강 안내

허리를 과도하게 굽히거나 젖히지 말고 통증이나 어지럼증 발생 시 중단하세요. 처음에는 가벼운 중량과 적은 세트로 시작하고 통증이 있는 동작은 제외하세요. 허리디스크 병력과 이석증·전정신경염 등 어지럼증 경험을 의료진 또는 물리치료사에게 알리고 운동 가능 여부를 먼저 확인하세요. 앱은 의료 진단이나 개인 재활 처방을 제공하지 않습니다.
